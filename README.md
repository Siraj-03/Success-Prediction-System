# Success-Prediction-System
Start-Up Success Prediction is an end-to-end Machine Learning and Deep Learning project designed to predict whether a startup will be acquired (successful) or closed (failed) based on factors such as funding history, investor profiles, business milestones, geographic location, and industry sector. The project leverages advanced predictive modeling techniques and Explainable AI to provide both accurate predictions and transparent insights into the factors influencing startup success.

🎯 Key Features
Comprehensive data preprocessing, cleaning, and feature engineering.
Class imbalance handling using SMOTE.
Comparative analysis of multiple Machine Learning models:
Logistic Regression
Support Vector Machine (SVM)
Random Forest
Gradient Boosting
XGBoost
Deep Learning implementations:
Artificial Neural Network (ANN)
Convolutional Neural Network (CNN)
Long Short-Term Memory (LSTM)
CNN-LSTM Hybrid
Explainable AI using SHAP and LIME for model interpretability.
Interactive Streamlit web application for real-time predictions.

📊 Results
Trained and evaluated models on a dataset of 923 startups with engineered business and funding-related features.
Achieved 86.9% Accuracy and 0.928 ROC-AUC using the CNN-LSTM Hybrid model.
Identified key success factors including funding rounds, investor strength, milestones achieved, and startup relationships.
